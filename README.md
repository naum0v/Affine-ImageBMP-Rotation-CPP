# Программное обеспечение процедур аффинных поворотов изображений

Данный репозиторий содержит проект на языке C++, представляющий собой высокопроизводительное консольное приложение для выполнения аффинных поворотов растровых изображений (формат BMP).

## Ключевые особенности

*   **Своя реализация работы с BMP:** Написаны модули чтения и записи BMP-файлов с нуля (поддержка 8, 24 и 32 бит на пиксель, обработка выравнивания строк по 4 байта, конвертация палитры).
*   **Методы интерполяции:** Реализованы два алгоритма расчета новых пикселей: метод ближайшего соседа (быстрый, но со ступенчатостью) и билинейная интерполяция (сглаживание).
*   **Многопоточность:** Реализовано распараллеливание вычислений с помощью `std::thread`.
    *   *Равномерное распределение:* каждый поток обрабатывает каждый N-й пиксель.
    *   *Блочное (тайловое) распределение:* изображение разбивается на блоки, которые обрабатываются параллельно.
*   **Замер производительности:** Встроенный модуль профилирования на базе `std::chrono` позволяет замерять время выполнения каждого алгоритма с точностью до миллисекунд.
*   **Консольный интерфейс:** Интерактивное текстовое меню для выбора типа поворота, угла, метода интерполяции и количества потоков.

## Архитектура

Приложение построено на базе многослойной архитектуры (Layered Architecture) с четким разделением ответственности:
1.  **Уровень представления:** Консольный интерфейс (меню).
2.  **Уровень бизнес-логики:** Менеджер обработки, координация потоков, сбор статистики.
3.  **Уровень обработки данных:** Математическое ядро (матрицы поворота, интерполяция).
4.  **Уровень доступа к данным:** Модуль ввода-вывода BMP и управление памятью.

Подробные схемы архитектуры и взаимодействия блоков находятся в папке `docs/`.

## Стек технологий

*   **Язык:** C++ (стандарт C++17/20)
*   **Многопоточность:** `std::thread`, `std::mutex`, `std::atomic`
*   **Сборка:** CMake

## Как собрать и запустить

1. Склонируйте репозиторий.
2. Убедитесь, что у вас установлен компилятор C++ (GCC/Clang/MSVC) и CMake.
3. Соберите проект в терминале (или используйте Visual Studio / CLion):
   ```bash
   cmake .
   cmake --build .
4. Запустите скомпилированный исполняемый файл (code или code.exe):
   ```bash
   ./code
5. В консоли появится меню для выбора BMP-файла и параметров его поворота.
